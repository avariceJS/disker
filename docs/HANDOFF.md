Updated: 2026-10-19.

## Product state

Disker is a native SwiftUI macOS app installed at `~/Applications/Disker.app`. It separately reports macOS-reported root-volume capacity and metadata estimates for explicitly selected folders or app bundles. Folder scans are no-follow, metadata-only, hard-link deduplicated per root, cancellable, and disclose partial coverage, races, overflow, logical bytes, allocated-byte estimates, and nested-volume boundaries. Different-device files and directories beneath a selected root are skipped and make coverage partial. User-confirmed duplicate verification applies the same boundary and coverage rule before reading file contents. Local bounded history supports comparable same-path, same-volume complete-scan growth and 24-hour, 7-day, 30-day, and all-retained charts. RAM metrics are distinct; optional five-minute samples and system pressure transitions run only while Disker is active and are off at relaunch.

Application attribution is user-selected and evidence-scoped: the Applications list uses persisted app-picker provenance, so a generic directory ending in `.app` is not misclassified, and older records retain this status only when they contain a bundle ID. After explicit selection, the list follows the latest measurement for that exact path, including saved-folder scans; older signature/identity evidence is never copied onto a newer measurement. Bundles are measured separately; declared/signed IDs and App Groups claims inform clearly qualified path suggestions; associated folders must be selected manually. A matching signed ID supports a conventional-container-path clue but does not prove the folder's origin or ownership. Project/development clues use exact directory names, Git markers, and filename extensions only. They are not ownership, contents, or disposability claims. Duplicate verification is a separate user-confirmed content read over up to 50 selected roots; an over-limit request is rejected before reading. Its dry-run plan requires a chosen keeper, retains exact paths, selected scope, timestamp, and SHA-256 evidence, and states that ownership, shared use, restore/reproduction options, risk, and reclaimable space are unknown. Disker has no file-deletion action. The About page measures only Disker's own bundle and dedicated support folder.
